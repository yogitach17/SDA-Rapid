### 🏆 Built for **InnovIClon Hackathon 2025**  

Synapse is a **real-time disaster alert and response system** that bridges the gap between citizens and authorities.  
It leverages **NASA-approved APIs, ISRO data, and Mapbox integration** to deliver accurate, location-based alerts during natural and man-made disasters.  

Our goal is simple yet powerful: **save lives, reduce economic losses, and strengthen community resilience** with cutting-edge AI and accessible technology.  

---

## 🚀 Features  

- **Real-Time Alerts** – SMS, push notifications, and app updates  
- **Community Reporting** – Upload geotagged photos, videos, and text  
- **AI-Powered Risk Analysis** – YOLOv8 + ML models  
- **NASA + ISRO APIs** – Trusted satellite & sensor data  
- **Mapbox Integration** – Disaster maps & visualizations  
- **Multilingual & Offline** – Works in diverse, low-connectivity areas  
- **Training Modules** – Disaster preparedness & awareness  
- **Centralized Dashboard** – Resource allocation for authorities  

---

## 🛠️ Tech Stack  

**Frontend:** React.js (Vite) + Tailwind CSS + TypeScript/JavaScript  
**Backend:** Supabase (Auth + Storage), Firebase Studio, SQL (JSONB)  
**APIs:** NASA (Approved) | ISRO | Government Data | Mapbox | SMS Gateway | Gemini/GPT  
**AI Models:** YOLOv8, AI-powered chatbot assistant  
**Deployment:** Vercel / Netlify, GitHub
